# Chapter lists / Kapitellisten

Copy one of these to `~/.config/xournalpp/lernordner-kapitel.tsv` and adapt it.
Kopiere eine davon nach `~/.config/xournalpp/lernordner-kapitel.tsv` und passe sie an.

```bash
cp examples/kapitel-beispiel.tsv ~/.config/xournalpp/lernordner-kapitel.tsv
```

| File | Content |
|---|---|
| `kapitel-beispiel.tsv` | small generic example / kleines Beispiel |
| `kapitel-allgemeinmedizin-chenot-scherer-2.tsv` | chapter titles of *Allgemeinmedizin* (Chenot/Scherer, 2nd ed.), 115 chapters in six parts – for owners of the book. Not affiliated with authors or publisher. / Kapiteltitel des Lehrbuchs *Allgemeinmedizin* (Chenot/Scherer, 2. Aufl.) für Besitzer:innen des Buchs; keine Verbindung zu Autor:innen oder Verlag. |

Format: one line per chapter, tab-separated: number, folder (part), title. Lines starting with `#` are ignored.
